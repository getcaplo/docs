tools

Section titled “tools”
Field Type Required Description
name string Yes Pattern ^[a-z][a-z0-9_]{0,47}$.
effect "read", "write" Yes
timeoutSeconds integer Yes From 1 to 30.
confirmation "required", "none" Write tools only. required (the default) runs the tool only after the customer confirms the call in a later turn.
subject object The tool acts for a verified customer. The runner passes the owner-verified subject in the call context, never through arguments; selector names an optional input property the runner fills with the subject’s resource reference and refuses from the model. See tools.subject.
presentation object Public form and receipt metadata. Only listed fields are ever shown; it grants no execution and exposes no other argument. The build checks every path against the tool’s schemas. See tools.presentation.
progress object Static customer-facing status while the tool runs. Frozen with the release and never interpolated. See tools.progress.
elicitation object Read tools only. While it runs, the tool may ask the visitor for missing details with MCP form elicitation (elicitation/create). A request may name only these fields; Caplo refuses one that asks for a credential, and offers elicitation only where the visitor can answer, so the tool must handle a client without the capability. See tools.elicitation.
