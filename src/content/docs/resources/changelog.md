Release notes for the CLI, with downloads and checksums, are on [GitHub](https://github.com/getcaplo/homebrew-tap/releases). Update with `brew upgrade getcaplo/tap/caplo` or rerun the [installer](/cli/install/).

## November 2026

- **Documentation.** docs.caplo.si launched, with guides for agents, tools, the website widget, provider keys, usage and the CLI. The [CLI reference](/reference/cli/) and the [agent](/reference/agent-yaml/), [caplo.yaml](/reference/caplo-yaml/) and [fixture](/reference/fixtures/) schemas are generated from each CLI release. Every page has a Markdown version and AI prompts for common tasks.
- **CLI 0.4.0.** Every command's help now explains its behavior and shows examples; the same text is the [CLI reference](/reference/cli/).
