## Use the docs with AI

The docs are written to be read by coding agents and chat assistants as well as people.

- Every page has a Markdown version. Replace the trailing slash of a page URL with `.md`: `/agents/publishing/` is `/agents/publishing.md`, and the home page is `/index.md`.
- `https://docs.caplo.si/llms.txt` lists every page with a short description, and `https://docs.caplo.si/llms-full.txt` is the whole site as one Markdown file.
- Task pages include an **AI prompt** you can copy, or open in Claude or ChatGPT, to have an assistant do the task in your own repository.
